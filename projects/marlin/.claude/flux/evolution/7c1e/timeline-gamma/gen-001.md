# Timeline-gamma, gen-001

## Approach

Precompute a time-expanded graph (node = stop at a time event) and run Dijkstra from the
origin's nearby stops. Cache per-origin-cell results so repeated pins near each other reuse work.

## Genome

```yaml
traits:

```

Safety check: experimental 0.5 is below the 0.6 threshold, and testing 0.4 is present
anyway. Allowed.

## Why this approach could win

- a cache hit makes the "couple of seconds" requirement trivial
- the graph form handles walking transfers and mode filtering uniformly as edge predicates

## Risks

- the user settings change the graph itself (allowed modes, max wait), so a cache keyed only
  on origin is wrong: the cache key must include every setting, which guts the hit rate
- time-expanded graph for a full day of SL is large in memory
- highest risk of being too slow to build, which is exactly what PROJEKT.md warns about
